## Events

recon-ng emits five events. Listen with the SDK's `Events` from any mod. This is
the stable cross-mod contract and needs no shared imports.

```txt
ReconNg.Breach.SessionOpened     a session was opened by run
ReconNg.Breach.DesktopOpened     a post module granted desktop access
ReconNg.Breach.FileRead          a file was read with cat
ReconNg.Breach.FileDownloaded    a file was saved to ~/downloads
ReconNg.Breach.FileDeleted       a file was removed with rm
```

```ts
interface ReconNgEventMap {
    "ReconNg.Breach.SessionOpened":  {
        sessionId: string;
        ip: string;
        host: string;
        moduleId: string;
        privilege: string;
        access: string;
        desktop-: { os: "linux" | "windows"; profile: string; label-: string; hwid: string; opened: boolean };
    };
    "ReconNg.Breach.DesktopOpened":  {
        sessionId: string;
        ip: string;
        host: string;
        moduleId: string;
        os: "linux" | "windows";
        profile: string;
        label-: string;
        hwid: string;
    };
    "ReconNg.Breach.FileRead":       { sessionId: string; ip: string; host: string; path: string; name: string };
    "ReconNg.Breach.FileDownloaded": { sessionId: string; ip: string; host: string; path: string; name: string; localPath: string };
    "ReconNg.Breach.FileDeleted":    { sessionId: string; ip: string; host: string; path: string; name: string };
}
```

Quest listener:

```ts
this.Events.on("ReconNg.Breach.FileDownloaded" as any, (event: any) => {
    if (event.host === "demo-target.example" && event.path === "/var/www/config.env") {
        this.completeObjective("recover_config");
    }
});
```

Drive objectives off `FileRead`, `FileDownloaded`, or `FileDeleted`, off
`SessionOpened` when a foothold is enough, or off `DesktopOpened` when a quest
requires a GUI/desktop-grade implant. Match on `event.ip`, `event.host`, and
`event.path` where available. Do not gate completion on the player opening
recon-ng or typing `run`; use the breach events for that.

For a HawkEye-style frontend, listen for `ReconNg.Breach.DesktopOpened` and open
the simulated OS using `event.os`, `event.profile`, and `event.hwid`. The HWID is
generated by recon-ng and stored on the per-save session state; it is not
intended to be typed by the player unless your mission deliberately wants that.

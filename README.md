# Overview

Recon-NG adds an interactive exploitation workspace to HackHub.
Identify exposed services, select matching exploit modules, configure targets, and open persistent remote sessions. Once connected, you can explore the remote filesystem, download files, escalate access, run post-exploitation modules, and return to previous sessions.

Similar to Spiderfoot, this custom terminal command was created first and foremost for my own mod, but I am releasing it here so that other mod authors can also use it, it is also a dependnency for my mod.

Like Spiderfoot, Recon-NG has its own handbook entries that explain the workflow and syntax of the command.

This mod was made in collaboration with the very talented tz1k (Check out his Nemesis Protocol mod) who fully developed and designed HawkEye.

Check out the full documentation complete with examples and a quick start guide here:
